# 3D model attribution

All bundled models are **CC0 (public domain)** — no attribution is legally required,
but provenance is recorded here for hygiene and so the kit can be regenerated/extended.

## Characters — Quaternius "Ultimate Space Kit"
- Source: https://quaternius.com/packs/ultimatespacekit.html
- License: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/
- Files (`characters/`): `Astronaut_*.gltf`, `Mech_*.gltf`, `Enemy_*.gltf`
- Self-contained glTF (embedded buffers + atlas texture). Rigged with an
  Idle/Walk/Run animation set (flyers use Flying_Idle/Fast_Flying).

## Characters — Quaternius "RobotExpressive" (pre-existing)
- CC0. The neutral animated robot used for the player + generic baseline.

## Buildings + props — Kenney "Space Kit" / "Space Station Kit"
- Source: https://kenney.nl/assets/space-kit , https://kenney.nl/assets/space-station-kit
- License: CC0 1.0
- Files (`buildings/`, `props/`): binary `.glb`, self-contained (embedded palette texture).
  Curated subset — hangars/structures/turret/dish/platform as POI buildings; barrels,
  pipes, rocks, meteor, craft, rover, container as scatter props.
