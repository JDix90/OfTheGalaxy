## 💡 Tips for Testing

1. **Start Simple:** Begin with basic greetings to verify systems are working
2. **Build Complexity:** Progress to more complex queries that test multiple systems
3. **Check Console:** Monitor console logs to see which systems are active
4. **Compare NPCs:** Test same input with different NPCs to see variation
5. **Repeat Tests:** Run tests multiple times to check for consistency
6. **Edge Cases:** Test unusual inputs to find bugs
7. **Performance:** Monitor response times and system load

---

## 📝 Test Result Template

For each test, note:

- **Input:** What you typed
- **Expected:** What you expected to see
- **Actual:** What actually happened
- **System Active:** Which Phase 1 systems were involved
- **Issues:** Any problems or unexpected behaviors
- **Notes:** Additional observations

Example:
```
Input: "Tell me about the Empire"
Expected: Faction-specific rhetoric, formal tone
Actual: Got Empire-specific response with formal language
System Active: Faction, Personality
Issues: None
Notes: Response felt authentic and in-character
```
