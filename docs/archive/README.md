# Documentation Archive

Historical design docs, phase records, analyses, and requirements from the
project's first development cycle (Nov 2025 – Feb 2026). These are kept for
reference but are **not authoritative** — many contain status claims that were
aspirational or have since been superseded. For the current, verified state of
the project see the root [`README.md`](../../README.md).

## Folders
- **phases/** — phase/priority/task implementation summaries and completion records.
- **analysis/** — system analyses, code reviews, and status assessments.
- **requirements/** — feature requirement specs, implementation plans, roadmaps.
- **consultant/** — external consultant feedback threads.
- **misc/** — guides, how-tos, and other one-off notes.

> When in doubt, trust the code and the root README over anything in here.
